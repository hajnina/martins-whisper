t
    fun `does not invent text`() {

## Dictation cases
1. Tap < 400 ms -> no insert, no audio saved.
2. Hold 2 s "hello world" -> exact text at cursor.
3. Hold 60 s with pauses -> complete, no duplicate boundary words at 25 s cuts.
4. Speak immediately after press -> first word not clipped (pre-roll).
5. Press while model unloaded -> records, shows loading, transcribes after load.
6. Hold 10 min -> safety cap behaves; app stable.
7. Switch model tiny->base in settings -> next dictation uses new model; old unloaded.
8. Idle 5 min -> status unloaded; memory/VRAM drop; next use reloads.
9. Airplane mode after model downloaded -> dictation still works; no network.
10. Screen rotate / multi-window / overlay drag / reboot -> overlay restores, position persists.
11. Revoke mic/overlay/accessibility while running -> clear error and recovery path.
12. Incoming call / another mic app -> graceful failure.
13. Screen off/on -> service alive; overlay not blocking.
14. Low battery / thermal throttling -> no crash; latency reported.
15. Accessibility off -> copy-to-clipboard + notification fallback.

## GPU / performance
- Settings/diagnostics shows backend (`vulkan`, `cpu`, `nnapi`).
- On Vulkan device: force GPU and CPU, transcribe same 10 s clip; record latency, memory.
- On non-Vulkan device: auto falls back to CPU with visible status.
- After idle unload, GPU memory returns (best-effort; vendor tools or `dumpsys meminfo`).
- Report battery impact for 10 dictations.
